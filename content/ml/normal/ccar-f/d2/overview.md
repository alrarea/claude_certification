## Tool Design & MCP Integration

ഈ ഡൊമെയ്ൻ (പരീക്ഷയുടെ 18%, ഏകദേശം 11 ചോദ്യങ്ങൾ) Claude-ഉം പുറംലോകവും തമ്മിലുള്ള ഇടനില പാളിയെക്കുറിച്ചാണ്: നിങ്ങൾ തുറന്നുകൊടുക്കുന്ന ടൂളുകളും, അവ എത്തിക്കുന്ന Model Context Protocol (MCP) സെർവറുകളും. നിങ്ങൾ നിയന്ത്രിക്കുന്നതിൽ ഏറ്റവും സ്വാധീനമുള്ള ഒരൊറ്റ കാര്യമായി പരീക്ഷ ടൂൾ വിവരണങ്ങളെ കണക്കാക്കുന്നു — Claude തെറ്റായ ടൂൾ തിരഞ്ഞെടുക്കുമ്പോഴോ, തെറ്റായ ക്രമത്തിൽ ടൂളുകൾ വിളിക്കുമ്പോഴോ, ഒരു ടൂൾ ബാധകമല്ലെന്ന് തിരിച്ചറിയാതിരിക്കുമ്പോഴോ അവ്യക്തമോ പരസ്പരം കൂടിക്കുഴഞ്ഞതോ ആയ ഒരു വിവരണമാണ് സ്ഥിരം മൂലകാരണം.

വ്യക്തിഗത ടൂൾ വിവരണങ്ങൾക്ക് അപ്പുറം, MCP സെർവർ ക്രമീകരണം (project vs. user scope, environment variable വികാസം), MCP tools-ഉം resources-ഉം തമ്മിലുള്ള വ്യത്യാസം, ഘടനാപരമായ പിഴവ് കൈകാര്യം (`isError` ഫ്ലാഗും പിഴവുകളെ താൽക്കാലികം, വ്യാപാരപരം, അനുമതിപരം എന്നിങ്ങനെ വർഗീകരിക്കലും), least privilege തത്ത്വം — യഥാർഥ ജോലിപരിധിക്ക് ആവശ്യമായ ടൂളുകൾ മാത്രം ഒരു agent-ന് നൽകുക, കാരണം അമിതമായ ടൂളുകൾ ടൂൾ തിരഞ്ഞെടുപ്പിന്റെ പ്രകടനം അളക്കാവുന്ന വിധം മോശമാക്കുന്നു — എന്നിവയും ഈ ഡൊമെയ്ൻ ഉൾക്കൊള്ളുന്നു.
