## Claude Code Configuration & Workflows

പരീക്ഷയുടെ 20% (ഏകദേശം 12 ചോദ്യങ്ങൾ) തൂക്കമുള്ള ഈ ഡൊമെയ്ൻ, നിങ്ങൾക്കായി മാത്രം ക്രമീകരിക്കുന്നതിനെക്കുറിച്ചല്ല — ഒരു മുഴുവൻ ടീമിനും സ്ഥിരതയുള്ളതും ഉയർന്ന നിലവാരമുള്ളതുമായ ഫലങ്ങൾ ലഭിക്കാൻ Claude Code എങ്ങനെ സജ്ജീകരിക്കാം എന്നതിനെക്കുറിച്ചാണ്. അതായത് മൂന്ന് തലങ്ങളിലുള്ള CLAUDE.md ശ്രേണി (user, project, directory) ഉം `@import` മാതൃകകളും മനസ്സിലാക്കുക, glob പൊരുത്തപ്പെടുത്തലോടെ `.claude/rules/` വഴി പാത-അധിഷ്ഠിത കീഴ്‌വഴക്കങ്ങൾ, project-പരിധിയിലുള്ളവ (`.claude/commands/`, git വഴി പങ്കിടുന്നത്) ഉം വ്യക്തിഗതമായവ (`~/.claude/commands/`, പ്രാദേശികം മാത്രം) ഉം തമ്മിലുള്ള വ്യത്യാസവും.

Claude Code പ്രവർത്തിപ്പിക്കുന്നതിന്റെ പ്രായോഗിക വശവും ഇത് ഉൾക്കൊള്ളുന്നു: വലുതും അവ്യക്തവും ആർക്കിടെക്ചറിൽ പ്രാധാന്യമുള്ളതുമായ മാറ്റങ്ങൾക്ക് നേരിട്ടുള്ള നിർവഹണത്തിന് പകരം plan mode തിരഞ്ഞെടുക്കുക; `context:fork`, `allowed-tools`, `argument-hint` പോലുള്ള skill frontmatter ഉപാധികൾ; സ്വയമേവയുള്ള ജോലികൾ മനുഷ്യ ഇൻപുട്ടിനായി കാത്തുനിന്ന് തടസ്സപ്പെടാതിരിക്കാൻ `-p` ഫ്ലാഗും `--output-format json`-ഉം ഉപയോഗിച്ച് CI/CD pipeline-കളിൽ Claude Code ഇടപെടലില്ലാതെ പ്രവർത്തിപ്പിക്കുക.
