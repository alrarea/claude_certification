# സംയോജനം (In-Depth)

19% (ഏകദേശം 12 ചോദ്യങ്ങൾ) വരുന്ന സംയോജനമാണ് പരീക്ഷയിലെ ഏറ്റവും വലിയ ഒറ്റ ഡൊമെയ്ൻ, ആ തൂക്കം ഒരു സൂചനയാണ്: ഒരു യഥാർഥ വിന്യാസത്തിൽ Claude ഒറ്റയ്ക്ക് പ്രവർത്തിക്കുന്നില്ല — അതിന് ഡാറ്റാബേസുകളിലേക്കും ആന്തരിക API-കളിലേക്കും ടൂളുകളിലേക്കും പലപ്പോഴും മറ്റ് agent-കളിലേക്കും ബന്ധിപ്പിക്കണം, ആ ബന്ധങ്ങൾ ശരിയായും സുരക്ഷിതമായും രൂപകൽപ്പന ചെയ്യാൻ നിങ്ങൾക്ക് കഴിയുമോ എന്ന് ഈ ഡൊമെയ്ൻ പരിശോധിക്കുന്നു.

മുഴുവൻ RAG pipeline-കളെക്കുറിച്ചും (ingest → chunk → embed → index → retrieve → generate) ആഴത്തിലുള്ള ഉള്ളടക്കം പ്രതീക്ഷിക്കുക — ഒരു സാഹചര്യത്തിന് ഏത് chunking തന്ത്രവും ഏത് retrieval സമീപനവും (അർഥാധിഷ്ഠിതം, keyword, hybrid, re-ranking) ഇണങ്ങുമെന്നതുൾപ്പെടെ. പുറത്തുള്ള സിസ്റ്റങ്ങളിലേക്ക് Claude *എങ്ങനെ* ബന്ധിപ്പിക്കണമെന്നും നിങ്ങൾ ചിന്തിക്കണം — MCP vs. നേരിട്ടുള്ള API വിളികൾ vs. agent-to-agent ആശയവിനിമയം — ഒപ്പം ടൂൾ, agent ക്രമീകരണത്തിൽ least-privilege ചിന്ത പ്രയോഗിക്കണം (വേണ്ടാത്ത കഴിവുകൾ നിരീക്ഷിക്കുക മാത്രമല്ല, നീക്കം ചെയ്യുക). ഒടുവിൽ, കൃത്യത-latency-ചെലവ് വിട്ടുവീഴ്ചകൾ ന്യായീകരിക്കാനും ഒരു പ്രൊഡക്ഷൻ AI സിസ്റ്റത്തിൽ യഥാർഥ observability എങ്ങനെയിരിക്കുമെന്ന് അറിയാനും ഈ ഡൊമെയ്ൻ പ്രതീക്ഷിക്കുന്നു — അഭ്യർഥനകൾ, പ്രതികരണങ്ങൾ, token എണ്ണം, latency, retrieval ഫലങ്ങൾ എന്നിവ ലോഗ് ചെയ്യൽ.

> **📝️ പരീക്ഷാ ശ്രദ്ധ:** Least privilege-ഉം RAG/retrieval പരാജയ നിർണയവും പ്രത്യേകിച്ച് ഫലപ്രദമാണ് — രണ്ടും ഔദ്യോഗിക മാതൃകാ ചോദ്യങ്ങളിൽ വരുന്നു.
