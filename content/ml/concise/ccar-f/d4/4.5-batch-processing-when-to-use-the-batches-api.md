title: Batch Processing — When to Use the Batches API

> **🔑️ പ്രധാന നിഗമനം:** ആരും തത്സമയം ഫലത്തിനായി കാത്തിരിക്കാത്ത വലുതും അടിയന്തരമല്ലാത്തതുമായ ജോലികൾക്ക് Batches API ഉപയോഗിക്കുക — ചെലവ് ഏകദേശം പകുതി, പക്ഷേ പൂർത്തിയാകാൻ 24 മണിക്കൂർ വരെ എടുക്കാം.

- സാധാരണ തത്സമയ API വിളികളേക്കാൾ ഏകദേശം 50% വില കുറവ്.
- പ്രോസസ്സിങ് സമയം: 24 മണിക്കൂർ വരെ — തത്സമയമല്ല, ഉടനടി പ്രതികരണം ഉറപ്പില്ല.
- batch-ലെ ഓരോ അഭ്യർഥനയിലും `custom_id` ഉപയോഗിക്കുക, അപ്പോൾ ഓരോ ഫലവും അതിന്റെ യഥാർഥ അഭ്യർഥനയുമായി ചേർക്കാനാകും.
- പരിമിതി: ഒരൊറ്റ batch അഭ്യർഥനയ്ക്കുള്ളിൽ പല turn-കളിലായുള്ള ടൂൾ വിളി സാധ്യമല്ല.
- ✅ ഉപയോഗിക്കേണ്ടത്: രാത്രി റിപ്പോർട്ടുകൾ, പ്രതിവാര ഓഡിറ്റുകൾ, രാത്രിയിലെ ടെസ്റ്റ് നിർമാണം, അടിയന്തരമല്ലാത്ത വൻതോതിലുള്ള രേഖാ പ്രോസസ്സിങ്.
- ❌ ഉപയോഗിക്കരുത്: merge-നു മുൻപുള്ള പരിശോധനകൾ, തത്സമയ ഉപഭോക്തൃ ഇടപെടലുകൾ, അല്ലെങ്കിൽ ആർക്കെങ്കിലും ഫലം ഉടനെ വേണ്ട എന്തും.
- തീരുമാനിക്കാനുള്ള ചോദ്യം: "ഈ പ്രതികരണത്തിനായി ഇപ്പോൾ ആരെങ്കിലും കാത്തിരിക്കുന്നുണ്ടോ?" ഇല്ലെങ്കിൽ — batch ചെയ്ത് ചെലവ് ലാഭിക്കുക.
