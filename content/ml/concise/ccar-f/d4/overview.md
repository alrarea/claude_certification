## Prompt Engineering-ഉം ഘടനാപരമായ ഔട്ട്പുട്ടും — ഉപവിഷയങ്ങൾ

- `tool_use`-ഉം JSON Schema-യും വഴി ഘടനാപരമായ ഔട്ട്പുട്ട്; nullable ഫീൽഡുകൾ; വാക്യഘടനാപരമായ vs. അർഥപരമായ കൃത്യത
- അവ്യക്തമായ സാഹചര്യങ്ങൾക്കും രൂപ സ്ഥിരതയ്ക്കും few-shot prompting
- അവ്യക്തമായ നിർദേശങ്ങൾക്കു പകരം വ്യക്തവും കൃത്യവുമായ മാനദണ്ഡങ്ങൾ
- വലുതോ സങ്കീർണമോ ആയ ഇൻപുട്ടുകൾക്ക് multi-pass review (per-file + integration pass)
- Message Batches API vs. തത്സമയ API — latency സഹിഷ്ണുതയ്ക്ക് ഇണങ്ങുന്നത് തിരഞ്ഞെടുക്കൽ
