> **🔑️ പ്രധാന നിഗമനം:** നീണ്ട session-കളിൽ നേരത്തേ കണ്ടെത്തിയ കൃത്യമായ വിവരങ്ങളിലുള്ള Claude-ന്റെ പിടി അയയുകയും, പകരം പൊതുവായ "സാധാരണ മാതൃക" അറിവ് ഉപയോഗിച്ചു തുടങ്ങുകയും ചെയ്യുന്നു — ഇതിനെ ചെറുക്കാൻ കണ്ടെത്തലുകൾ തത്സമയ സംഭാഷണത്തിനു പുറത്ത് സൂക്ഷിക്കുക.

- **Context ശോഷണം:** നേരത്തേ കണ്ടെത്തിയ കൃത്യമായ കാര്യങ്ങൾ agent മറക്കുകയും, യഥാർഥ കോഡിനു പകരം പൊതുവായ മാതൃകകളിലേക്ക് മടങ്ങുകയും ചെയ്യുന്നു.
- **Scratchpad ഫയലുകൾ:** പ്രധാന കണ്ടെത്തലുകൾ ഒരു ഫയലിൽ എഴുതുക; പിന്നീടുള്ള ചോദ്യങ്ങളിൽ സംഭാഷണ ഓർമയെ ആശ്രയിക്കാതെ ആ ഫയൽ പരാമർശിക്കുക.
- **Subagent-കൾക്ക് ഏൽപ്പിക്കൽ:** നീണ്ട പര്യവേക്ഷണം subagent-കളിലേക്ക് മാറ്റുക; പ്രധാന agent ബഹളമല്ല, ഉയർന്ന തലത്തിലുള്ള ഏകോപനം മാത്രം സൂക്ഷിക്കുന്നു.
- **`/compact`:** ഇതിനകം നീണ്ട ഒരു session-ൽ ഇടം വീണ്ടെടുക്കാൻ session context സംഗ്രഹിക്കുകയോ ചുരുക്കുകയോ ചെയ്യുന്നു.
- **ഘടനാപരമായ state കയറ്റുമതി:** ഓരോ agent-ഉം അതിന്റെ state ഒരു ഫയലിൽ സൂക്ഷിക്കുന്നു; തുടരുമ്പോൾ coordinator അത് വീണ്ടും വായിക്കുന്നു — തകർച്ചയിൽ നിന്നുള്ള വീണ്ടെടുക്കലും ഇത് സാധ്യമാക്കുന്നു.
- പൊതു സൂത്രം: നീണ്ട session-കളിൽ തത്സമയ സംഭാഷണത്തെ സത്യത്തിന്റെ ഒരേയൊരു ഉറവിടമായി വിശ്വസിക്കരുത് — സൂക്ഷിക്കുകയും ബോധപൂർവം വീണ്ടും ചേർക്കുകയും ചെയ്യുക.
