> **🔑️ പ്രധാന നിഗമനം:** ടീം പങ്കിടുന്ന MCP server-കൾക്ക് പ്രോജക്റ്റ് ഫോൾഡറിലെ `.mcp.json` ഉപയോഗിക്കുക (version control-ൽ വരുന്നത്), വ്യക്തിപരമോ പരീക്ഷണാത്മകമോ ആയവയ്ക്ക് ഹോം ഫോൾഡറിലെ `~/.claude.json` ഉപയോഗിക്കുക (പ്രാദേശികം മാത്രം, ഒരിക്കലും പങ്കിടുന്നില്ല).

- `.mcp.json` (പ്രോജക്റ്റ് ഫോൾഡർ) — ടീമിലെ എല്ലാവരും കാണുന്നു, git-ൽ commit ചെയ്യുന്നു, ടീം മുഴുവൻ വേണ്ട ടൂളുകൾക്ക്.
- `~/.claude.json` (ഹോം ഫോൾഡർ) — ആ ഡെവലപ്പർ മാത്രം കാണുന്നു, version control-ൽ ഇല്ല, വ്യക്തിപരമോ പരീക്ഷണാത്മകമോ ആയ ടൂളുകൾക്ക്.
- `.mcp.json` git വഴി പങ്കിടുന്നതിനാൽ അതിൽ ഒരിക്കലും രഹസ്യങ്ങൾ നേരിട്ട് എഴുതരുത്.
- യഥാർഥ രഹസ്യ മൂല്യങ്ങൾ commit ചെയ്ത ഫയലിലല്ല, environment variable-കളിൽ നിൽക്കാൻ `${VARIABLE_NAME}` എന്ന ഘടന ഉപയോഗിക്കുക (ഉദാ: `"token": "${GITHUB_TOKEN}"`).
