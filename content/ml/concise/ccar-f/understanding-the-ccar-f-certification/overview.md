## CCAR-F സർട്ടിഫിക്കേഷൻ മനസ്സിലാക്കാം — സംഗ്രഹം

- CCAR-F പരിശോധിക്കുന്നത് വസ്തുതകൾ ഓർത്തെടുക്കലല്ല, **യഥാർഥ സാഹചര്യങ്ങളിലെ വിവേചനബുദ്ധിയാണ്** — ഓരോ ചോദ്യവും "ഇതാണ് സാഹചര്യം, നിങ്ങൾ എന്ത് ചെയ്യും?" എന്ന രൂപത്തിലാണ്.
- **5 പരീക്ഷാ ഡൊമെയ്നുകൾ** (നിശ്ചിത തൂക്കം; ഏത് സാഹചര്യങ്ങൾ വന്നാലും ഓരോ തവണയും ഇവ വരും):
  - D1 Agentic Architecture & Orchestration — 27% (~16 ചോദ്യങ്ങൾ) — ഏറ്റവും ബുദ്ധിമുട്ടുള്ള ഡൊമെയ്ൻ
  - D3 Claude Code Configuration & Workflows — 20% (~12 ചോദ്യങ്ങൾ)
  - D4 Prompt Engineering & Structured Output — 20% (~12 ചോദ്യങ്ങൾ)
  - D2 Tool Design & MCP Integration — 18% (~11 ചോദ്യങ്ങൾ)
  - D5 Context Management & Reliability — 15% (~9 ചോദ്യങ്ങൾ)
- **കൃത്യമായി അറിഞ്ഞിരിക്കേണ്ട പ്രധാന സാങ്കേതികവിദ്യകൾ:**
  - Claude Agent SDK — സ്വയം പ്രവർത്തിക്കുന്ന, ടൂളുകൾ ഉപയോഗിക്കുന്ന, പല ഘട്ടങ്ങളുള്ള agent-കൾ ഉണ്ടാക്കാൻ
  - MCP (Model Context Protocol) — Claude-നെ പുറത്തുള്ള ടൂളുകളുമായും ഡാറ്റയുമായും ബന്ധിപ്പിക്കുന്ന ഏകീകൃത "plugin സംവിധാനം"
  - Claude Code — നിങ്ങളുടെ വികസന പരിസരത്തിനുള്ളിൽ പ്രവർത്തിക്കുന്ന CLI agent
  - Claude API — പ്രോഗ്രാം വഴിയുള്ള ഇടപെടൽ (prompt-കൾ, പ്രതികരണങ്ങൾ, ടൂൾ നിർവചനങ്ങൾ)
  - Message Batches API — വൻതോതിൽ, ചെലവ് കുറവ്, 24 മണിക്കൂർ വരെ സമയം — തത്സമയ ആവശ്യങ്ങൾക്ക് **അല്ല**
  - JSON Schema — Claude-ൽ നിന്ന് പ്രതീക്ഷിക്കുന്ന ഔട്ട്പുട്ടിന്റെ കൃത്യമായ ഘടന നിർവചിക്കുന്നു
  - Pydantic — Claude-ന്റെ ഔട്ട്പുട്ട് ആ ഘടനയോട് ഒത്തുപോകുന്നുണ്ടോ എന്ന് പരിശോധിക്കുന്നു

> **📝️ പരീക്ഷാ ശ്രദ്ധ:** ശരിയായ latency/വിശ്വാസ്യതാ ആവശ്യവുമായി ശരിയായ സാങ്കേതികവിദ്യ ചേർക്കുന്നതിലാണ് (പ്രത്യേകിച്ച് Batches API vs. തത്സമയ API) സാഹചര്യ ചോദ്യങ്ങൾ കേന്ദ്രീകരിക്കുക എന്ന് പ്രതീക്ഷിക്കുക.
