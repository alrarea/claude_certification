# വിലയിരുത്തൽ, പരിശോധന, ഒപ്റ്റിമൈസേഷൻ (Concise)

- പ്രധാന അളവുകൾ: കൃത്യത, latency, ചെലവ്, സുരക്ഷ, hallucination നിരക്ക്
- അതിർത്തി സാഹചര്യങ്ങളും യഥാർഥ ഉത്തരങ്ങളുമുള്ള വിലയിരുത്തൽ ഡാറ്റാസെറ്റുകൾ രൂപകൽപ്പന ചെയ്യൽ
- A/B testing: ഒരു സമയത്ത് ഒരു ഘടകം മാത്രം മാറ്റുക, ഒരേ eval ഡാറ്റാസെറ്റ്
- ലക്ഷണങ്ങളിൽ നിന്ന് പരാജയങ്ങൾ കണ്ടെത്തൽ (ഉറപ്പോടെയുള്ള തെറ്റുത്തരങ്ങൾ → retrieval പ്രശ്നം)
- ചെലവ് കുറയ്ക്കാനുള്ള ഉപാധികൾ: caching, മോഡലിന്റെ വലുപ്പം, batch API, max_tokens
