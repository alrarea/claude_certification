> **🔑️ പ്രധാന നിഗമനം:** നിങ്ങൾ ആരാണെന്ന് Authentication പരിശോധിക്കുന്നു; നിങ്ങൾക്ക് എന്ത് ചെയ്യാൻ അനുവാദമുണ്ടെന്ന് authorization പരിശോധിക്കുന്നു — ഓരോ ടൂൾ വിളിയിലും രണ്ടും നടപ്പാക്കണം, audit logging സംഭവങ്ങളുടെ രേഖയാണ്, ഇവയ്ക്ക് രണ്ടിനും പകരമല്ല.

- **Authentication** = സ്വത്വ പരിശോധന (login, API key). ഓരോ ടൂൾ വിളിയും authenticate ചെയ്യപ്പെടണം.
- **Authorization** = ഒരു പ്രത്യേക നടപടിക്കുള്ള അനുമതി പരിശോധന. ഓരോ session-ലും ഒരിക്കൽ മാത്രമല്ല, ഓരോ നടപടിക്കും മുൻപ് അനുമതി പരിശോധിക്കുക.
- Authenticate ചെയ്യപ്പെട്ടു എന്നത് authorize ചെയ്യപ്പെട്ടു എന്ന് **അർഥമാക്കുന്നില്ല** — ഇവ രണ്ട് സ്വതന്ത്ര പരിശോധനകളാണ്.
- **Least privilege** ആണ് authorization-നു പിന്നിലെ നയം: വേണ്ട ഏറ്റവും കുറഞ്ഞ പ്രവേശനം മാത്രം നൽകുക; ഒരു agent-ന് വേണ്ടാത്ത ടൂളുകൾ നീക്കുക.
- **Audit logging** ആര്, എന്ത്, എപ്പോൾ ചെയ്തു എന്ന് രേഖപ്പെടുത്തുന്നു — compliance-ന് ആവശ്യമാണ്, പക്ഷേ പൂർണമായും പ്രതികരണാത്മകമാണ്; least privilege-നോ ശരിയായ authorization നടപ്പാക്കലിനോ ഒരിക്കലും പകരമല്ല.
