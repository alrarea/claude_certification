> **🔑️ പ്രധാന നിഗമനം:** ഒരു agent-ന് അതിന്റെ യഥാർഥ ജോലിക്ക് വേണ്ട ടൂളുകൾ മാത്രം നൽകുക — ടൂളുകൾ അധികമുള്ള ഒരു agent-ന്റെ ശരിയായ least-privilege പരിഹാരം എപ്പോഴും അനാവശ്യ ടൂളുകൾ നീക്കം ചെയ്യുകയാണ്, അവയ്ക്ക് ചുറ്റും ലോഗിങ്ങോ സ്ഥിരീകരണമോ ചേർക്കുകയല്ല.

- Least privilege = ജോലി ചെയ്യാൻ വേണ്ട ഏറ്റവും കുറഞ്ഞ ടൂളുകളും അനുമതികളും, അധികമൊന്നുമില്ല.
- പരമ്പരാഗത കോഡിനെക്കാൾ LLM agent-കൾ കൂടുതൽ അപകടസാധ്യതയിലാണ്, കാരണം ഏത് ടൂൾ വിളിക്കണമെന്ന് നിശ്ചയിക്കുന്നത് നിശ്ചിത യുക്തിയല്ല, ന്യായവാദമാണ് — prompt injection-ഉം അവ്യക്തതയും ഉദ്ദേശിക്കാത്ത ടൂൾ ഉപയോഗത്തിന് കാരണമാകാം.
- പരീക്ഷാ കെണി: അമിത അധികാരമുള്ള ഒരു agent-നെ സാഹചര്യം കാണിക്കുന്നു; "സ്ഥിരീകരണം ചേർക്കുക," "ലോഗിങ് ചേർക്കുക," "മനുഷ്യന്റെ അനുമതി ചേർക്കുക" എന്നിവ ആകർഷകമായ തെറ്റുത്തരങ്ങളാണ്.
- **ശരിയായ ഉത്തരം മിക്കവാറും എപ്പോഴും: അനാവശ്യ ടൂളുകൾ പൂർണമായി നീക്കം ചെയ്യുക** — അതാണ് ഒരേയൊരു യഥാർഥ least-privilege പരിഹാരം.
- ലോഗിങ്, സ്ഥിരീകരണം, അനുമതി എന്നിവ സാധുവായ *അധിക* പ്രതിരോധ നടപടികളാണ്, പക്ഷേ ഉണ്ടാകാൻ പാടില്ലാത്ത പ്രവേശനം നീക്കം ചെയ്യുന്നതിന് അവ പകരമാകില്ല.
