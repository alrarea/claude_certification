# പരീക്ഷാ ഗൈഡിലെ മാതൃകാ ചോദ്യങ്ങൾ (Concise)

വേഗ ഉത്തരസൂചിക — ഓരോന്നിനും ശരിയുത്തരവും ഒറ്റവരി കാരണവും.

1. **Least-privilege ടൂൾ നീക്കം ചെയ്യൽ (D3 Integration):** ✅ **B** — റീഫണ്ട്/delete ടൂളുകൾ പൂർണമായി നീക്കുക. ആവശ്യമില്ലാത്ത കഴിവ് least privilege ഒഴിവാക്കുന്നു; ലോഗിങ്ങും സ്ഥിരീകരണ ചോദ്യങ്ങളും ദുരുപയോഗം സംഭവിച്ച ശേഷമേ കണ്ടെത്തൂ.
2. **ഓരോ അഭ്യർഥനയിലും അയക്കുന്ന സ്ഥിരമായ 8K-token prompt (D2 Models/Prompting):** ✅ **C** — സ്ഥിരമായ ഉള്ളടക്കം ആദ്യം വെച്ച് prompt caching ഓണാക്കുക. ചെലവും latency-യും ഒരുമിച്ച് കുറയ്ക്കുന്ന ഒരേയൊരു വഴി ഇതാണ്.
3. **രേഖകൾ പുതുക്കിയ ശേഷം RAG ഉറപ്പോടെ തെറ്റുത്തരങ്ങൾ നൽകുന്നു (D4 Evaluation):** ✅ **B** — ആദ്യം retrieval/indexing പരിശോധിക്കുക. ഉറപ്പോടെ തെറ്റ് + മോഡലും latency-യും മാറിയിട്ടില്ല = ഇത് retrieval പ്രശ്നമാണ്, മോഡലിന്റെ പ്രശ്നമല്ല.
