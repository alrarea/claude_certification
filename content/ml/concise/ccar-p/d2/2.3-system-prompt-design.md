> **🔑️ പ്രധാന നിഗമനം:** Claude-ന്റെ ഏറ്റവും ഉയർന്ന അധികാരമുള്ള നിർദേശമാണ് system prompt — അത് സ്വത്വവും പരിമിതികളും നിശ്ചയിക്കുന്നു, user സന്ദേശങ്ങൾക്ക് അതിനെ മറികടക്കാനാകില്ല; അതുകൊണ്ട് എപ്പോഴും പാലിക്കപ്പെടേണ്ട എന്തിനും ശരിയായ സ്ഥാനം ഇതാണ്.

- അധികാരത്തിൽ system prompt > user സന്ദേശങ്ങൾ — user ഇൻപുട്ടിന് ഇതിനെ മറികടക്കാനാകില്ല.
- അഞ്ച് നിർമാണ ഘടകങ്ങൾ: role നിർവചനം, ജോലിയുടെ അതിരുകൾ, ഔട്ട്പുട്ട് രൂപം, guardrail-കൾ, സ്വരം.
- സുരക്ഷാപരമോ ബിസിനസ് നിർണായകമോ ആയ എന്തും ഓരോ turn-ലെയും user നിർദേശങ്ങളിലല്ല, ഇവിടെ വെക്കുക.
- version ചെയ്ത ക്രമീകരണമായി കണക്കാക്കുക — വാക്കുകളിലെ മാറ്റം പെരുമാറ്റത്തെ വ്യാപകമായി മാറ്റുന്നതിനാൽ, കോഡ് പോലെ മാറ്റങ്ങൾ review ചെയ്യുകയും പരിശോധിക്കുകയും ചെയ്യുക.
- കൃത്യതയിൽ സന്തുലനം: വളരെ അവ്യക്തം = ദുർബലമായ പരിമിതി; വളരെ വിശദം = വഴക്കമില്ലാത്ത, ഉപകാരമില്ലാത്ത agent.
